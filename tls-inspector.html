How this works

This tool uses the Anthropic API to run the TLS inspector logic and return structured results. It replicates the checks from tls_inspector.py — expiry, hostname match, signature algorithm, key size, protocol version, self-signed detection, SANs, and basic constraints.

To run locally instead: pip install cryptography then python tls_inspector.py example.com
